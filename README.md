### 🚀 Proyectos Destacados

* **[TEP – Sistema de Gestión de Almacén e Inventario](https://github.com/P4lomaP/TEP-Sistema-Inventario-Ayala-Puyol)** *(Práctica Profesional – Tribunal Electoral Permanente de Formosa)*  
  Plataforma web de control de stock, matriz de compatibilidad y trazabilidad patrimonial. Desarrollada con **Node.js, Express, React, Vite, Tailwind CSS y MySQL (InnoDB)**, con autenticación **JWT**, **RBAC**, logs inmutables y actas en PDF.

* **Sistema Montessori – Portal Institucional Escolar Digital** *(EPEP N.° 548)*  
  Plataforma web modular para gestión escolar (asistencia, comedor, biblioteca, armario digital, horarios y actos). Base de datos de **38 tablas en MySQL**, frontend en **HTML5, Tailwind CSS y JavaScript (Fetch API)**, backend en **PHP (PDO)** y criterios **WCAG 2.1**.

* **FixTime – Sistema de Gestión Integral para Taller Mecánico** *(Taller Mecánica Torales)*  
  Aplicación web multi-rol en **PHP (POO, MVC, Repository, PDO)**, **JavaScript** y **MySQL** para gestión de turnos, órdenes de reparación, presupuestos y stock, con integración de **API de Mercado Pago** y recordatorios vía **PHPMailer**.
